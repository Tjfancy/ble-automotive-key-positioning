## 2. 信号模型

### 2.1 物理场景

```
                    θ = 30°
                       ▲
                      /|
                     / |
                    /  |
         ┌───────┐  /   │  平面波
         │  ●  ●  ●  ●  │  ← M 个阵元，间距 d = λ/2
         └───────┘
    ←───── d ─────→
```

- 均匀线阵（ULA），M 个全向阵元
- 阵元间距 d = λ/2（避免栅瓣，保证角度无模糊范围 ±90°）
- 载波频率 2.4 GHz（BLE ISM 频段），波长 λ ≈ 12.5 cm
- 远场单源入射，来波方向 θ（与阵法线的夹角）

### 2.2 导向矢量

相邻阵元间的相位差由波程差决定：

$$\Delta\phi = \frac{2\pi}{\lambda} \cdot d \cdot \sin\theta = \frac{2\pi}{\lambda} \cdot \frac{\lambda}{2} \cdot \sin\theta = \pi \sin\theta$$

因此导向矢量为：

$$a(\theta) = \begin{bmatrix} 1 \\ e^{j\pi\sin\theta} \\ e^{j2\pi\sin\theta} \\ \vdots \\ e^{j(M-1)\pi\sin\theta} \end{bmatrix}$$

**物理意义**：第 m 个阵元相对于参考阵元（第 0 个）的相位滞后为 m·π·sinθ，这是阵列信号处理的基石。

### 2.3 接收信号

对于 K 个快照（采样时刻），接收数据矩阵为：

$$X = a(\theta) \cdot s + n$$

- X：(M × K) 复数矩阵，M 个阵元各采样 K 次
- s：(K,) 复数源信号，功率 E[|s|²] = 1（单位功率假设）
- n：(M × K) 复高斯白噪声，n ~ CN(0, σ²I)

**SNR 定义**：

$$\text{SNR (dB)} = 10 \log_{10}\left(\frac{P_s}{P_n}\right) = 10 \log_{10}\left(\frac{1}{\sigma^2}\right)$$

所以噪声功率 σ² = 10^(-SNR/10)。

### 2.4 参数含义汇总

| 参数 | 含义 | 示例值 | 影响 |
|------|------|--------|------|
| M | 阵元数 | 4, 8, 16 | 越多 → 阵列孔径越大 → 分辨率越高 → 精度越高 |
| θ_true | 真实入射角 | 30° | 待估计量 |
| K | 快照数 | 200 | 越多 → 协方差估计越准 → 精度越高 |
| SNR | 信噪比 | -10 ~ 30 dB | 越高 → 噪声越小 → 精度越高 |
| d/λ | 阶元间距/波长 | 0.5 (λ/2) | 避免栅瓣，保证 ±90° 无模糊 |

## 3. 算法原理

### 3.1 前置：协方差矩阵与特征分解

接收数据的协方差矩阵：

$$R = \frac{1}{K} X X^H$$

对 R 做特征分解：

$$R = V \Lambda V^H = \sum_{i=1}^{M} \lambda_i v_i v_i^H$$

特征值满足 λ₁ ≥ λ₂ ≥ ... ≥ λ_M ≥ 0。

**关键性质**：对于 p 个信源，前 p 个大特征值对应**信号子空间**，后 M-p 个小特征值对应**噪声子空间**：

$$\text{span}\{v_1, ..., v_p\} = \text{span}\{a(\theta_1), ..., a(\theta_p)\}$$

$$\text{span}\{v_{p+1}, ..., v_M\} \perp \text{span}\{a(\theta_1), ..., a(\theta_p)\}$$

即 **噪声子空间与信号子空间正交**——这是 MUSIC 和 ESPRIT 的共同理论基础。

### 3.2 MUSIC 算法

**全称**：MUltiple SIgnal Classification（多重信号分类）

**核心思想**：利用噪声子空间与导向矢量的正交性。

**步骤**：

```
1. 计算 R = (1/K)·X·X^H
2. 特征分解 R，特征值降序排列
3. 噪声子空间 Un = [v_{p+1}, ..., v_M]   (M × (M-p))
4. MUSIC 空间谱：
   P_MUSIC(θ) = 1 / (a^H(θ) · Un · Un^H · a(θ))
5. 在 θ ∈ [-90°, 90°] 搜索谱峰 → 角度估计
```

**物理意义**：

- 当 a(θ) 指向真实来波方向时，a(θ) 完全落在信号子空间内，与噪声子空间正交
- 此时分母 a^H·Un·Un^H·a → 0，谱值 P_MUSIC(θ) → ∞（出现尖峰）
- 当 a(θ) 不指向任何真实方向时，分母较大，谱值很小

**特点**：

| 优点 | 缺点 |
|------|------|
| 分辨率高，可分辨相干信源（需预处理） | 需要全角度网格搜索，计算量大 O(M²·N_θ) |
| 基于噪声子空间，精度高 | 对信源数 p 敏感（需已知或估计 p） |
| 经典算法，理论成熟 | 网格分辨率限制精度（0.5° 网格 → 极限精度） |

**本项目实现**：网格步长 0.5°，搜索范围 [-90°, 90°]。

### 3.3 ESPRIT 算法

**全称**：Estimation of Signal Parameters via Rotational Invariance Techniques

**核心思想**：利用 ULA 的平移不变性，不需要全角度搜索。

**步骤**：

```
1. 计算 R，特征分解，取信号子空间 Es = [v_1, ..., v_p]  (M × p)
2. 子阵划分：
   Es1 = Es[0:M-1, :]    前 M-1 行
   Es2 = Es[1:M, :]      后 M-1 行
3. 存在 p×p 矩阵 Ψ 满足：Es2 = Es1 · Ψ
   求解：Ψ = pinv(Es1) · Es2
4. 特征分解 Ψ，特征值 λ_k = exp(j·π·sinθ_k)
5. 反解：θ_k = arcsin(angle(λ_k) / π)
```

**物理意义**：

- ULA 的前 M-1 个阵元和后 M-1 个阵元接收同一信号，仅相差一个相位旋转
- 这个相位旋转 = π·sinθ，直接编码了入射角信息
- ESPRIT 把这个几何关系转化为代数特征值问题，直接求解

**特点**：

| 优点 | 缺点 |
|------|------|
| 无需角度搜索，计算量小 O(M³) | 对信源数 p 敏感 |
| 代数求解，无网格分辨率限制 | 低 SNR 时稳定性略逊 MUSIC |
| 适合实时系统 | 子阵划分损失 1 个阵元自由度 |

### 3.4 MUSIC vs ESPRIT 对比

| 维度 | MUSIC | ESPRIT |
|------|--------|--------|
| 精度（低 SNR） | 更好（噪声子空间约束强） | 略逊 |
| 精度（高 SNR） | 受网格分辨率限制 | 无网格限制，理论上更优 |
| 计算量 | O(M²·N_θ) 需搜索 | O(M³) 直接求解 |
| 实现复杂度 | 中等 | 较简单 |
| 适用场景 | 离线分析、高精度 | 实时系统、嵌入式 |

## 4. 实验与结果

### 4.1 单场景验证

**条件**：M=8, K=200, SNR=10 dB, θ_true=30°

| 算法 | 估计角度 | 误差 |
|------|---------|------|
| MUSIC | 30.000° | 0.000° |
| ESPRIT | 30.006° | +0.006° |

**结论**：两个算法在高 SNR 下都能准确估计角度，验证了实现的正确性。

**输出图表**：`results/music_spectrum.png`（MUSIC 空间谱，30° 处有尖锐谱峰）

### 4.2 蒙特卡洛实验设计

**固定参数**：θ_true = 30°, K = 200

**扫描参数**：

| 参数 | 取值 |
|------|------|
| SNR | -10, -5, 0, 5, 10, 15, 20, 25, 30 dB |
| M | 4, 8, 16 |
| 每组试验次数 | 50 |

共 9 × 3 = 27 组参数组合，每组 50 次独立试验。

**评估指标**：RMSE（均方根误差）

$$\text{RMSE} = \sqrt{\frac{1}{N}\sum_{i=1}^{N}(\hat{\theta}_i - \theta_{\text{true}})^2}$$

### 4.3 结果分析

#### RMSE vs SNR（固定 M）

| M | SNR=-10 | SNR=0 | SNR=10 | SNR=30 |
|---|---------|-------|--------|--------|
| 4 | MUSIC 2.74° | 0.53° | 0.17° | 0.00° |
| 4 | ESPRIT 3.64° | 0.53° | 0.16° | 0.02° |
| 8 | MUSIC 0.78° | 0.14° | 0.00° | 0.00° |
| 8 | ESPRIT 1.18° | 0.19° | 0.05° | 0.01° |
| 16 | MUSIC 0.31° | 0.00° | 0.00° | 0.00° |
| 16 | ESPRIT 0.50° | 0.11° | 0.04° | 0.00° |

**规律一：SNR 提升显著改善精度**

- 从 -10 dB 到 0 dB，RMSE 急剧下降（噪声主导 → 信号主导）
- >10 dB 后趋于饱和（受限于快照数 K 和网格分辨率）
- 这是阵列信号处理的典型特征：存在"阈值效应"

**规律二：MUSIC 在低 SNR 下优于 ESPRIT**

- 在 -10 dB 时，MUSIC 的 RMSE 明显小于 ESPRIT（如 M=4: 2.74° vs 3.64°）
- 原因：MUSIC 利用了完整的噪声子空间约束，在低 SNR 时更稳健
- 高 SNR 时两者接近（MUSIC 受 0.5° 网格分辨率限制出现 0.00° 假象）

**规律三：阵元数越多精度越高**

- M 从 4 → 8 → 16，低 SNR 下精度提升约 9 倍（2.74° → 0.31°）
- 物理原因：阵元数越多 → 阵列孔径越大 → 角度分辨率越高 → 波束越窄
- 这是实际部署的核心结论：**增加天线数量是提升 AoA 精度最有效的手段**

#### RMSE vs M（固定 SNR）

- SNR=-10 dB 时，M=4→16 使 MUSIC RMSE 从 2.74° 降至 0.31°（改善 89%）
- SNR=30 dB 时，各 M 下 RMSE 均接近 0（高 SNR 下阵元数不再是瓶颈）
- 曲线随 M 增加呈递减趋势，符合阵列孔径理论

**输出图表**：

| 图表 | 文件 |
|------|------|
| RMSE vs SNR（6 条曲线） | `results/mc_rmse_vs_snr.png` |
| RMSE vs M（多 SNR 曲线） | `results/mc_rmse_vs_M.png` |
| MUSIC 空间谱 | `results/music_spectrum.png` |
| 原始数据 | `data/mc_results.npz` |

### 4.4 关键结论（面试可直接讲）

1. **SNR 是精度的硬约束**：低 SNR（<0 dB）下测角误差大，工程上需保证足够的信号功率
2. **阵元数是性价比最高的改进手段**：M 加倍，低 SNR 下精度约提升一倍
3. **MUSIC 稳、ESPRIT 快**：低 SNR 选 MUSIC，实时系统选 ESPRIT
4. **快照数 K 同样重要**：K 越多协方差估计越准确，但增加采集时间

## 5. 可拓展方向

### 5.1 算法层面

| 方向 | 说明 |
|------|------|
| **多信源估计（p > 1）** | 目前只做了 p=1。扩展到 p>1 需要解决信源数估计（AIC/MDL 准则）和多谱峰配对问题 |
| **相干信源** | MUSIC 对相干信源失效，需空间平滑（SS-MUSIC）或最大似然（ML）方法 |
| **TLS-ESPRIT** | 总最小二乘版本的 ESPRIT，比 LS-ESPRIT 在低 SNR 下更稳健 |
| **2D AoA** | 均匀圆阵（UCA）或均匀面阵（URA）可估计方位角 + 仰角，更贴近实际车载天线布局 |

### 5.2 信号模型层面

| 方向 | 说明 |
|------|------|
| **多径效应** | 实际车载环境存在反射，信号模型从单径扩展到多径（Multipath） |
| **阵列校准** | 实际阵元间存在幅相不一致性，需加入阵列流形误差校准 |
| **互耦效应** | 密集阵元间的电磁互耦，影响导向矢量精度 |

### 5.3 系统融合层面

| 方向 | 说明 |
|------|------|
| **RSSI + AoA 融合** | 用 RSSI 做粗定位、AoA 做精测角，EKF 融合可提升鲁棒性 |
| **与 UWB 对比** | 数字钥匙场景中 UWB 精度更高但成本高，BLE AoA 是成本与精度的折中 |
| **安全扩展** | AoA 的距离估计可用于抗中继攻击（Relay Attack），是数字钥匙安全的核心议题 |

### 5.4 工程实现层面

| 方向 | 说明 |
|------|------|
| **真实硬件采集** | nRF53/54 + QM33110 天线阵列，采集 I/Q 数据跑真实 AoA 算法 |
| **嵌入式部署** | 将 MUSIC/ESPRIT 移植到 MCU，评估计算资源消耗 |
| **实时性优化** | ESPRIT 适合实时，可进一步优化特征分解的数值稳定性 |
